# Bijbeldata

`bible_svv.json` bevat de **Statenvertaling** (66 canonieke boeken, zonder apocriefen).
De tekst is afkomstig uit [scrollmapper/bible_databases](https://github.com/scrollmapper/bible_databases)
(bestand `DutSVV.json`, MIT-licentie) en omgezet met `tools/make_bible.py`.

De Statenvertaling (1637) is publiek domein. Let op: controleer de rechtenstatus van een
specifieke uitgave/spelling voordat je de data commercieel verspreidt.
Moderne vertalingen (NBV21, HSV, BGT, …) zijn auteursrechtelijk beschermd en vereisen een licentie.
